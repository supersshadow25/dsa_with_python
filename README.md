# Data Structures and Algorithms with Python

Welcome to the **dsa_with_python** repository! This project contains a collection of Data Structures and Algorithms (DSA) implementations, Python object-oriented programming concepts, and practice problems.

---

## 📁 Repository Structure

### Data Structures & Algorithms
* `linked-list1.py` & `linked-list.txt` – Linked List implementation and notes.
* `queue.py` – Queue implementation.
* `tree-binary.py` & `tree-binary2.py` – Binary Tree implementations.
* `tree-binary-search.py` & `tree-binary-search2.py` – Binary Search Tree (BST) operations, including node deletion.
* `tree.txt` – Notes on Tree concepts.
* `time compleixty.txt` – Notes on time complexity analysis.

### String & Array Problems
* `anagram.py` – Anagram checks.
* `palindrome.py` – Palindrome checks.
* `duplicate.py` – Finding duplicate elements.
* `find-the-biggest.py` – Finding the maximum element in a list.
* `vowels.py` – Operations related to vowels.
* `special-char.py` – Special character handling.
* `title.py`, `count.py`, `marksheet.py`, `salary.py` – Practical scripting & utility problems.

### Python OOP & Core Concepts
* `instrance-var.py` & `instrance-var1.py` – Demonstrations of instance variables.
* `static-var.py` & `static-var1.py` – Demonstrations of static variables.
* `dict.py` – Dictionary usage and operations.
